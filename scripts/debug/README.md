# Debug Scripts

This folder collects scratch utilities, one-off inspectors, and investigative scripts used while aligning the converter, generator, and solver pipelines.

## Scripts

- `debug_compare_T.py` - Compare travel-time values between sources.
- `debug_energy.py` - Inspect energy computations and input data.
- `debug_inspect_39.py` - Inspect a specific data point or instance slice.
- `debug_inspect_stop.py` - Inspect stop-level JSON data.
- `debug_json_stops.py` - Inspect stop lists inside a JITS JSON file.
- `debug_mismatches.py` - Find mismatches between expected and generated values.
- `debug_ref_gen_values.py` - Inspect reference generator values.
- `debug_run_executor.py` - Exercise the execution path and solver runner.
- `debug_segment.py` - Inspect a specific data segment.
- `inspect2.py` - JSON inspection helper.
- `inspect3.py` - JSON inspection helper.
- `inspect4.py` - JSON inspection helper.
- `inspect_json.py` - General JSON inspection helper.
- `explore_integer_search_variants.py` - Explore alternative integer search variants.
- `task_script.py` - Miscellaneous task-oriented helper.

## Notes

- These scripts are not part of the stable public workflow.
- They should be treated as investigative helpers and may change as the repo evolves.
